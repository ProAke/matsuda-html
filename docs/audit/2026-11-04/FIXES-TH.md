# ผลแก้ไขตามรายงานตรวจเทียบ

## แก้ความเข้าใจเรื่อง “11 หน้า” ก่อน

รายงานก่อนหน้าอ้างผลอ่าน `Page 1 from 11` เป็นตัวบ่งชี้ว่ามี 11 หน้า แต่การตรวจครั้งนี้เปิด URL `awarded.php?page=1` ถึง `page=11` แล้วพบ:

| URL page | เอกสารที่ผลอ่านแสดง | ข้อความ pagination |
|---|---:|---|
| 1 | 6 | Page 1 from 11 |
| 2 | 0 | Page 2 from 1 |
| 3 | 0 | Page 3 from 1 |
| 4 | 0 | Page 4 from 1 |
| 5 | 0 | Page 5 from 1 |
| 6 | 0 | Page 6 from 1 |
| 7 | 0 | Page 7 from 1 |
| 8 | 0 | Page 8 from 1 |
| 9 | 0 | Page 9 from 1 |
| 10 | 0 | Page 10 from 1 |
| 11 | 0 | Page 11 from 1 |

นี่เป็นผลอ่านที่ขัดกัน ไม่ใช่หลักฐานว่ามีเอกสาร 11 หน้าจริง อาจเกิดจากการต่อข้อความ total `1` กับลิงก์เลขหน้า `1` ในผลอ่าน แต่ยังไม่มี raw DOM ยืนยัน จึง **ไม่สรุปสาเหตุเป็นข้อเท็จจริง** และแก้ข้อสรุปเดิมว่า “เอกสารยังขาด 10 หน้า” เป็น **“จำนวนหน้าต้นฉบับยังยืนยันไม่ได้; ตรวจพบจริง 6 เอกสาร”**

หลักฐานแบบ machine-readable: `data/awards-source-review.json` ระบุ URL ที่ตรวจครบทั้ง 11 URL ไม่มีการสร้างใบรับรองหรือหน้าเปล่าเพิ่ม

## โครงสร้างเนื้อหาปัจจุบัน
- `data/site.json`: ชื่อบริษัท ทุน หุ้น โทรศัพท์ แฟกซ์ อีเมลและลิงก์บริษัทแม่
- `data/locales/{lang}.json`: เนื้อหา/ป้าย/ที่อยู่รายภาษา (ยังต้องตรวจรับโดยเจ้าของภาษา)
- `data/documents.json`: แผนที่ รูปเอกสารนโยบายและภาษาจริงของเอกสาร
- `data/assets.json`: รูปเดิมและเอกสารรางวัล 6 ฉบับที่ตรวจพบ
- `data/legacy/*.json`: snapshot จาก export เพื่ออ้างอิงเท่านั้น **ไม่ใช่เนื้อหาที่ active page แสดงอีกต่อไป**

## ข้อที่ยังรับรองไม่ได้
1. ยังไม่ยืนยัน live ไทย/ญี่ปุ่น/จีนครบทั้ง 21 หน้า; คำแปลใหม่เป็นร่างจากข้อมูลที่ยืนยันได้ ไม่ใช่คำแปลที่เจ้าของภาษารับรอง
2. ยังไม่มีเอกสารรางวัลเพิ่มเติมจากหน้า 2–11 และไม่ยืนยันว่ามีหน้าเอกสารเหล่านั้นจริง
3. ยังไม่มีระบบรับ Feedback ฝั่งเซิร์ฟเวอร์ ต้องเลือกบริการถ้าต้องการส่งจากหน้าเว็บโดยตรง
4. ไม่ตรวจรับอายุใบรับรอง ไม่แปล/เปลี่ยนเอกสารนโยบายทางการ และไม่อ้างว่าฟอร์มเก่าฝั่ง PHP ใช้งานได้
5. Static hosting ต้องรองรับ redirects ตามกฎโฮสต์เอง กฎ Nuxt Node ผ่านการตรวจ HTTP แต่ไม่ใช่การตั้งค่า production hosting ให้แล้ว

## ผลทดสอบรอบแก้ไข
- Unit/content tests: **18 ผ่าน**
- Production build และ static generation: ผ่าน
- Browser: 28 routes, รูป local, 1280/768/375 px, mobile menu, language switch, carousel, 404 ผ่าน
- Regression: รูป Related Links/Business คืนครบทุกภาษา; ไม่พบข้อความส่วนเกิน; form validation และ mailto draft ผ่านครบ 4 ภาษา; แก้ข้อความแล้ว draft เก่าถูกล้าง
- URL รางวัล `?page=11` แสดงคำชี้แจงและเอกสารจริง 6 ฉบับ ไม่อ้างเป็นหน้าที่ 11
- HTTP 301 legacy redirects ผ่านการตรวจ; ไม่พบ console/hydration errors บนหน้าปกติที่ทดสอบ
- External Google Maps ถูก stub ระหว่าง browser tests ไม่ใช่ผลตรวจบริการ Maps จริง
